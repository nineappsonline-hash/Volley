# Volleyra — النسخة التفسيرية بالمصري

تم استبدال عرض النقاط المختصرة بعرض من ٤٢ شريحة، كل شريحة فيها فقرات تشرح الاحتياج، وطريقة عمل الميزة، ومثالًا أو توضيحًا عمليًا. المحتوى الرئيسي حوالي ٣٨٠٠ كلمة، بالإضافة إلى ملاحظات للمقدّم وملحق توثيق تفصيلي.

افتح `Volleyra-العرض-التفصيلي.pptx` للتعديل، أو `Volleyra-العرض-التفصيلي.pdf` للعرض والمشاركة. ملف `دليل-العرض-وحصر-المميزات.md` يحتوي النص التفسيري كاملًا والملحق، و`العرض-الكامل.html` نسخة للقراءة في المتصفح.

مصدر النسخة الحالية هو `narrative.txt`، ويمكن إعادة بناء ملفاتها بتشغيل `python3 deliverables/volleyra-presentation/build_narrative.py` من جذر المشروع. يحتاج السكريبت python-pptx؛ ثم يتم تحويل ملف PowerPoint إلى PDF باستخدام LibreOffice. `narrative.json` هو المحتوى المولد، و`narrative-context-notes.json` يحفظ التوضيحات الإضافية.

`slides.json` و`build_presentation.py` مصدر النسخة القديمة بالنقاط، محفوظان كمرجع للمراجعة فقط؛ لا تشغل سكريبت النسخة القديمة لإعادة بناء النسخة الحالية. `source-inventory.json` يوثق ملفات المصدر التي شملها فهرس المراجعة السابقة.

الأسعار والخصائص حسب كود سبتمبر ٢٠٢٦، ولم يتم اختبار الخدمة الحية. الأمثلة افتراضية وليست بيانات عملاء. لا يوجد حساب ولي أمر مستقل لربط الأطفال في النسخة الحالية. ملاحظات المقدّم تشرح حدود التنفيذ بدون تقديم الوعود غير المكتملة كخدمات مؤكدة.

للحفاظ على المظهر عند المشاركة استخدم PDF. للتعديل بنفس الخط في PowerPoint استخدم Noto Sans Arabic.
