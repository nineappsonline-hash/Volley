# Playza — خطة محتوى SEO للسوق المصري
## (لعب، ملاعب، بطولات، أكاديميات)

**الهدف:** الظهور في الصفحات الأولى على جوجل مصر لأهم كلمات البحث الرياضية، وتحويل الزوار إلى: لاعبين يبحثون عن ماتش أو ملعب، أولياء أمور، أصحاب ملاعب، ومنظمي بطولات وأكاديميات.

**الجمهور المستهدف (بترتيب حجم البحث المتوقع):**

1. **لاعبون بيدوّروا على لعب** — ماتش ودية، أهلي، جيمز
2. **أصحاب ملاعب** — عرض الملاعب والحجز
3. **أولياء أمور** بيدوّروا على تدريب لأولادهم
4. **منظمو بطولات** (أهلي / شركات / جامعات)
5. **أصحاب أكاديميات** (الإدارة)

**اللغة:** كل المحتوى بالعامية المصرية أو عربي بسيط — نفس نبرة صفحة الهبوط الحالية. الإنجليزي يُستخدم فقط في keywords metadata للكلمات المختلطة (padel، football pitch).

## 2. بنية الموقع الجديدة (Site Architecture)

**قاعدة URLs:** slugs إنجليزية قصيرة + عناوين ووصف بالعربي — هذا النمط هو اللي بيكسب SERP في مصر.

```
/                                   → الصفحة الرئيسية (لاعبين + أكاديميات)
/academies                          → دليل الأكاديميات (موجود)
/a/[slug]                           → صفحة الأكاديمية (موجود)
/venues                             → دليل الملاعب (جديد) ← أكبر فرصة SEO
/venues/[sport]                     → ملاعب {الرياضة} (جديد)
/venues/[sport]/[area]              → حجز ملعب {رياضة} في {منطقة} (جديد)
/venues/venue/[slug]                → صفحة الملعب (جديد)
/games                              → الماتشات الودية والأهلية (جديد)
/games/[sport]                      → ماتشات {الرياضة} الودية (جديد)
/tournaments                        → دليل البطولات (جديد)
/tournaments/[sport]                → بطولات {الرياضة} (جديد)
/tournaments/t/[slug]               → صفحة البطولة (جديد)
/for-venues                         → حلول أصحاب الملاعب (جديد)
/solutions/[sport]                  → حلول الأكاديميات (موجود — 5 صفحات)
```

**قاعدة مضادة للعقاب:** صفحات [الرياضة × المنطقة] تُبنى **فقط** عند وجود ملاعب/ماتشات فعلية فيها. صفحة بلا بيانات حقيقية = thin content وممكن يضرك. نبدأ بـ: التجمع، مصر الجديدة، المعادي، مدينة نصر، 6 أكتوبر، الشيخ زايد، الإسكندرية — ونوسع حسب نمو البيانات.

## 3. خطة المحتوى (3 مراحل)

### المرحلة 1 — أساسات (الأسبوع 1-3)

| # | الصفحة | الكلمات المستهدفة | ملاحظات |
|---|---|---|---|
| 1 | **دليل الملاعب `/venues`** | حجز ملعب، دليل الملاعب الرياضية | كل ملعب مسجل = صفحة قابلة للفهرسة |
| 2 | **صفحات [رياضة × منطقة]** | حجز ملعب كرة قدم في التجمع | إلزامي: ملاعب فعلية، سعر الساعة، مواعيد، خريطة |
| 3 | **صفحات الملاعب `/venues/venue/[slug]`** | اسم الملعب + المنطقة + السعر | SportsActivityLocation schema + صور حقيقية |
| 4 | **`/games` + `/games/[sport]`** | ماتشات أهلي، جيمز ودية، لعب كرة قدم اليوم | روابط بارزة من الهوم وإلا الصفحة مش هتتبني |
| 5 | **`/tournaments` + `/tournaments/[sport]`** | بطولات أهلية، بطولات شركات | قائمة بطولات مفتوحة للتسجيل |
| 6 | **`/for-venues`** | نظام إدارة ملاعب، برنامج حجز ملاعب | نفس نمط `/solutions` + Offer schema بـ EGP |

| # | الصفحة | الكلمات | نوع المحتوى |

|---|---|---|

## 4. الربط الداخلي (Internal Linking)

- **الهوم:** 4 كتل روابط واضحة: للعب (→ /games) • للحجز (→ /venues) • البطولات (→ /tournaments) • الأكاديميات (→ /academies)
- **الفوتر:** كل الحلول + أعلى المناطق + أعلى الرياضات
- **كل مقال يرتبط بـ:** صفحة الرياضة×المنطقة الأقرب + /games + /venues
- **Breadcrumbs + schema** في كل صفحة جديدة (مطبّق بالفعل عبر `breadcrumbsJsonLd`)
- **Anchor text وصفي بالعربي:** «حجز ملعب بادل في التجمع» — مش «اضغط هنا»
- **قاعدة الـ 3 نقرات:** أي ملعب أو بطولة أو أكاديمية ≤ 3 نقرات من الهوم
- **منع الصفحات اليتيمة:** كل صفحة منطقة لازم تكون مربوطة من /venues ومن مقال واحد على الأقل

## 5. قائمة فحص On-page (لكل صفحة جديدة)

- Title بالعربي + المنطقة/الرياضة — ≤ 60 حرف (بدون تكرار اسم البراند؛ القالب بيضيفه تلقائيًا)
- H1 واحد بالعربي
- H2s تحتوي تنويعات الكلمة: «أسعار حجز ملعب بادل في التجمع»، «أقرب ملاعب بادل إليك»
- الأسعار والمواعيد داخل نص الصفحة — جوجل يفضّل الصفحات اللي فيها بيانات فعلية
- FAQPage schema (3-5 أسئلة شائعة) في صفحات الملاعب والبطولات
- SportsActivityLocation schema للملاعب، SportsEvent للبطولات
- og-image خاص بكل نوع: الملاعب → `cover_url` الحقيقي
- Canonical لكل صفحة (الإصلاح القائم بيتطبق — نحافظ عليه)
- LCP أقل من 2.5 ثانية: صور WebP، lazy load، hero priority

## القواعد الذهبية

1. **جوجل ترتّب صفحات، مش مواقع.** كل كلمة بحث محتاجة صفحة مخصصة تجاوب عليها بعمق + بيانات فعلية.
2. **الفهرسة محتاجة صفحات عامة.** أي محتوى خلف تسجيل الدخول = غير مرئي للسوق (نفس مشكلة /academies اللي اتصلحت).
3. **البيانات الحقيقية هي الخندق التنافسي.** أسعار فعلية، ملاعب فعلية، تقييمات فعلية — ده اللي المنافس مش قادر ينسخه، وده اللي يخلي Playza المصدر الأول.
