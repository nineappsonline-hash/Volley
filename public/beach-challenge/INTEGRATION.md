Hand artwork: original articulated geometry, tapered forearms, anatomical palm masses, three-section fingers, knuckles and nails. Low receives join the forearms and fold the hands, overhead sets open both hands, and spikes raise the striking arm. Confirmed contacts retain ball height and player jump height; anticipation never generates a contact. Rules 1.2.0 requires the ball above relative shoulder height for a spike. Fullscreen uses the host container with a clearly labeled toggle and a viewport-sized expanded fallback when the API is unavailable.

Mobile controls/performance fix (rules 1.2.1): one pointer per joystick/look role; action fingers retain ownership until release/cancel; joystick direction is relative to the initial finger contact with a dead zone. Releasing another finger cannot reset movement. Mobile look is manual; reach/landing assistance remains available. Movement acceleration is normalized and point breaks clear active input. Resume uses a monotonic deadline and ignores the first inactive render gap. Mobile pause panels avoid expensive backdrop blur.

Mobile Auto/Medium/Low rendering uses Lambert lighting, lower mesh tessellation, no MSAA or dynamic shadows, and at most 650,000 drawing-buffer pixels. Anatomical hands and their poses are retained; finger instance matrices are reused until the pose changes. An emulated 390×844 / DPR 3 device recorded 12,804 triangles and 58 render calls at 1× render scale. These are complexity measurements, not physical-phone FPS claims.
